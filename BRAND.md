# Merge Queue Brand System

## Brand idea

**Controlled convergence.** Merge Queue protects independent intent until a human-reviewed commit brings compatible work together. The identity visualizes that product truth: three visible routes resolve into one deliberate output.

The personality is exacting, calm, and editorial. It should feel closer to an architecture studio's drawing set than a generic developer dashboard.

## Logo

The convergence mark is the primary symbol. Its upper and lower routes represent parallel work, cobalt identifies staged agent intent, and the vermilion node marks the reviewed result.

- Use [`logo-lockup.svg`](./assets/brand/logo-lockup.svg) as the default horizontal signature.
- Use [`logo-lockup-inverse.svg`](./assets/brand/logo-lockup-inverse.svg) on ink or photography.
- Use [`logo-mark.svg`](./assets/brand/logo-mark.svg) for compact placements.
- Use [`logo-mark-mono.svg`](./assets/brand/logo-mark-mono.svg) where only one color is available.
- Use [`app-icon.svg`](./assets/brand/app-icon.svg) for square app placements; the generated PNG sizes are production exports. The full-bleed maskable variant is reserved for install surfaces that apply their own crop.

Give the mark clear space equal to the height of one input terminal. Do not rotate it, add effects, recolor individual routes, or place it on visually busy detail.

## Palette

| Role | Value | Use |
| --- | --- | --- |
| Ink | `#1A1A1A` | Primary type, frames, main/human route |
| Paper | `#F5F3EE` | Brand canvas and warm neutral ground |
| Surface | `#FFFFFF` | Operational product surfaces |
| Agent | `#3157D5` | Agent proposals and staged machine intent |
| Focus | `#E4552F` | Focus, attention, and the commit node |
| Success | `#23745B` | Safe and committed product state |
| Warning | `#B85C22` | Recoverable caution |
| Danger | `#A63A2A` | Failed or irreversible outcome only |

Ink and paper should carry most compositions. Cobalt and vermilion are signals, not decoration.

## Typography

- Display and product sans: `Avenir Next`, then `Avenir`, `Helvetica Neue`, and system sans fallbacks.
- Technical labels and revision data: `SFMono-Regular`, then `Consolas` and `Liberation Mono`.
- Use tight display tracking for the name. Keep uppercase to short operational labels.

## Voice

Write with calm precision. Name the actor, the action, and the consequence. Prefer “Agent proposal,” “Save to main,” and “Commit merge” over invented branded vocabulary. The brand line is:

> Concurrent work. One deliberate commit.

## Graphic language

Routing lines, registration marks, ruled grids, and tactile paper/metal surfaces form the supporting visual language. Use them only when they clarify parallel work, review, or resolution.

## Production notes

The runtime product tokens remain owned by `styles.css`; `DESIGN.md` mirrors the accepted semantic values and explains their application. Brand SVGs use those same values directly so exports stay portable outside the application.
